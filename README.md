# pi-goal

**基于 codemode 实现，零初始上下文注入，无额外工具注入。**

设置一个目标，让 Pi 持续推进，直到完成、受阻或暂停，无需反复说“继续”。

```text
/goal 修复登录问题，并通过相关测试
```

| 命令 | 用途 |
| --- | --- |
| `/goal <目标>` | 设置或替换唯一目标，开始执行 |
| `/goal` | 查看目标、状态和累计运行时间 |
| `/goal pause` | 暂停（也支持 `/goal parse`） |
| `/goal resume` | 恢复暂停或受阻的目标 |
| `/goal clear` | 结束目标 |

仅运行时显示状态提示。暂停、清除不会中断正在执行的工具。
频繁重复尝试或连续失败会自动暂停；重新打开会话不会自动续跑。
